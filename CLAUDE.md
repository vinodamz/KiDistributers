# Ki Distributers — working notes

Sister app to Little Graduates. Same gstack conventions, same PHP/MySQL stack, distribution domain instead of school.

## gstack

Install on your own machine (not in this repo):

```bash
git clone --single-branch --depth 1 https://github.com/garrytan/gstack.git ~/.claude/skills/gstack \
  && cd ~/.claude/skills/gstack && ./setup
```

Use `/browse` for web browsing. Never `mcp__claude-in-chrome__*`.
